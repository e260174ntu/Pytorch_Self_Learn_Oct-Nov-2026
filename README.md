# PyTorch Self-Learning (Oct - Nov 2026)

This repository documents my systematic self-learning journey in Deep Learning and PyTorch during October and November 2026.

## 📖 Learning Materials
The core curriculum is based on the excellent open-source book **"Dive into Deep Learning" (D2L)**:
- English Version: [d2l.ai](https://d2l.ai/)
- Chinese Version: [zh.d2l.ai](https://zh.d2l.ai/)

## 📂 Repository Structure & Learning Methodology

To ensure steady progress, the directories are organized chronologically by the date of study. The repository contains two main types of files:

1. **`.ipynb` (Jupyter Notebooks)**: 
   - Textbook code walk-throughs, mathematical derivations, and experimental modifications of the D2L materials.
2. **`.py` (Python Scripts)**: 
   - Scripts converted and refactored from the notebooks. 
   - **To ensure deep understanding, I added extensive, line-by-line comments to these scripts.** These annotations explain the underlying tensor operations, mathematical logic (e.g., backward propagation, custom layers, training loops), and PyTorch API usage, ensuring I truly understand the mechanics rather than just running the code.
